# Финансовая грамотность — личный кабинет ученика

Одностраничное приложение для учеников репетитора Тимура Шафеева. Проект создан на базе React, Vite, Tailwind CSS и Supabase (через REST API) и содержит три ключевых раздела: тренажёр карточек, теорию и расписание занятий.

## Быстрый старт

```bash
npm install
npm run dev
```

Приложение стартует на [http://localhost:5173](http://localhost:5173).

### Переменные окружения

Создайте файл `.env` в папке `app` при использовании Supabase:

```env
VITE_SUPABASE_URL=your-project-url
VITE_SUPABASE_ANON_KEY=your-anon-key
```

При отсутствии переменных автоматически включается офлайн-режим с локальными JSON-данными и localStorage.

### Основные сценарии

- **Авторизация по коду** — проверка доступных кодов через Supabase (таблица `access_codes`) или локальный мок.
- **Прогресс учеников** — сохраняется в Supabase (`progress`) или в `localStorage`.
- **Карточки и теория** — загружаются из Supabase (`training_cards`, `theory`) либо из JSON-файлов.
- **Расписание** — таблица мероприятий с фильтрами по статусу, данные Supabase (`schedule`) или JSON.

## Структура

- `src/components` — интерфейсные блоки (личный кабинет, тренажёр, теория, расписание).
- `src/services/supabaseClient.js` — клиент Supabase с fallback на локальные данные.
- `src/data` — мок-данные для офлайн-режима.
- `tailwind.config.js` — тема интерфейса и глобальные стили.
